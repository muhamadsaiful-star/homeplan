3Pengaturan ekspor

Cara membuka di AutoCAD

  1. Unduh file DXF.
  2. Di AutoCAD: File → Open, pilih tipe file DXF.
  3. Edit per layer: LAHAN, DINDING, ARSIR, PINTU, JENDELA, FURNITUR, DIMENSI, TEKS.

Ukuran ruangan dihitung dari as ke as dinding. Ruangan yang berhimpitan memakai satu dinding bersama, dan jendela hanya dipasang di dinding luar. Pintu "Auto" dipilih ke sisi yang berbatasan dengan ruangan lain (ruang tamu dan garasi menghadap depan). Dimensi berupa garis dan teks biasa (bukan objek DIMENSION) agar mudah diedit.

Pratinjau Denah

Perubahan input langsung tampil di kanvas. Satuan gambar: meter.
